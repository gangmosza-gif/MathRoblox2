## สิ่งที่เปลี่ยนในหน้าจอ
1. เมนูขั้นตอนด้านซ้าย 4 ขั้น แทนแถบปุ่มบนหัว พร้อมไฮไลต์ขั้นที่กำลังทำ
2. หน้าต่างยืดหดได้จริง ทุกหน้าใช้ TableLayoutPanel ไม่ใช้พิกัดตายตัว ขั้นต่ำ 1120x760
3. แถบความคืบหน้าด้านซ้ายล่าง บอก ข้อมูลรายงาน / ผลตรวจ / Template ตลอดเวลา
4. แถบสถานะด้านล่าง บอกว่ายัง Export ไม่ได้เพราะอะไร โดยไม่ต้องกดปุ่มก่อน
5. หน้า 1 แบ่งข้อมูล 15 ช่องเป็น 4 กลุ่มการ์ด ช่องที่จำเป็นมีดอกจันและพื้นสีอ่อนเมื่อยังว่าง
6. คืนปุ่ม **ล้างค่าจำทั้งหมด** และ **เริ่มสาขาใหม่** ที่หายไปใน V0.7 ตามข้อกำหนดใน Handoff
7. เพิ่มปุ่ม **วันนี้** ข้างช่องวันที่ เติมวันที่แบบไทย เช่น 1 กันยายน 2569
8. หน้า 2 ลากไฟล์ Excel มาวางได้ ลบไฟล์ออกจากรายการได้ ตารางผลใส่สีตามสถานะ
9. หน้า 3 การ์ดรายข้อ มีป้ายสถานะ Mapping และป้ายแหล่งข้อมูล MANUAL / AUTO_DRAFT / AUTO_CONFIRMED และค้นหาหัวข้อได้
10. หน้า 4 มีรายการตรวจก่อน Export แบบเห็นผลทันที ตารางสรุปแหล่งข้อมูล 11 ข้อ และช่องบันทึกการทำงาน
11. Export Gate เปลี่ยนจาก MessageBox ข้อความยาว เป็นหน้าต่างยืนยันที่แสดงตารางแหล่งข้อมูลรายข้อ
12. คีย์ลัด F5 = Scan, Ctrl+E = Export, Ctrl+S = บันทึกค่าจำ, Ctrl+1 ถึง Ctrl+4 = สลับหน้า
13. เลือกฟอนต์อัตโนมัติตามที่เครื่องมี Leelawadee UI ก่อน แล้วค่อย Segoe UI และ Tahoma

## กฎเดิมที่ยังรักษาไว้
- ข้อมูลรายงานครบ 15 ช่อง
- Export ถูก Block ถ้าข้อมูลจำเป็นไม่ครบ หรือผลตรวจข้อใดข้อหนึ่งว่าง
- ต้องกดตรวจ Template และผ่านก่อน ปุ่ม Export จึงทำงาน
- ต้องกดยืนยันที่ Export Gate ก่อนสร้างไฟล์ กด ยกเลิก แล้วต้องไม่มีไฟล์เกิดขึ้น
- ผลตรวจ Manual ใช้กับ Mapping ที่ยัง Pending ได้
- Output เป็นไฟล์ใหม่เสมอ ไม่ทับไฟล์เดิม
- ไม่แก้ไขไฟล์ Excel ต้นฉบับ

## การรัน
`Run-AuditOnsiteReport.bat` เหมือนเดิม (Windows PowerShell 5.1, -STA, -NoProfile, -ExecutionPolicy Bypass)

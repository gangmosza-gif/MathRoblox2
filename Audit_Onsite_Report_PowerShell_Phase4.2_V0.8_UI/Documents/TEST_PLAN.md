# Test Plan Phase 4.2 V0.8 UI

## ก. ทดสอบว่าไม่มีอะไรพัง (Regression)
1. เปิดโปรแกรมผ่าน Run-AuditOnsiteReport.bat ต้องไม่มี Error
2. หน้า 1 ต้องมีข้อมูลรายงานครบ 15 ช่อง
3. ติ๊ก จำค่า แล้วปิดเปิดโปรแกรมใหม่ ค่าต้องยังอยู่
4. Scan ข้อ 3.2 แล้วป้ายแหล่งข้อมูลต้องเป็น AUTO_DRAFT
5. กรอกข้ออื่นด้วยมือ ป้ายต้องเปลี่ยนเป็น MANUAL
6. กดตรวจ Template ต้องขึ้น Placeholder 28/28 และปุ่ม Export ต้องเปิด
7. กด Export แล้วกดยกเลิกที่หน้ายืนยัน ต้องไม่มีไฟล์ใน Output
8. กดยืนยัน ต้องได้ไฟล์ใหม่ Placeholder ตกค้าง 0
9. เปิดไฟล์ Word ตรวจฟอนต์ TH SarabunPSK สีดำ คำว่า ลับ สีแดงบนล่าง และ Layout ทุกหน้า
10. ตรวจว่าจำนวนย่อหน้าว่างท้ายเอกสารที่ลบ ตรงกับที่รายงานในช่องบันทึกการทำงาน

## ข. ทดสอบ UI ใหม่
11. ย่อขยายหน้าต่างจนเล็กสุด ทุกหน้าต้องไม่มีปุ่มหรือตารางหลุดขอบ
12. ปุ่ม เริ่มสาขาใหม่ ต้องล้างข้อมูลสาขาและผลตรวจ แต่คงค่าที่ติ๊กจำไว้
13. ปุ่ม ล้างค่าจำทั้งหมด ต้องล้างเฉพาะค่าที่จำ ไม่ลบข้อความในช่อง
14. ปุ่ม วันนี้ ต้องเติมวันที่แบบไทย เช่น 1 กันยายน 2569
15. ลากไฟล์ .xlsx มาวางในกรอบไฟล์ ต้องเพิ่มเข้ารายการ และไฟล์ซ้ำต้องไม่ถูกเพิ่มสองครั้ง
16. เลือกไฟล์ในรายการแล้วกด นำออกจากรายการ ต้องหายไปทั้งจากรายการและจากหน่วยความจำ
17. พิมพ์คำค้นในหน้า 3 ต้องกรองการ์ดผลตรวจถูกต้อง และล้างคำค้นแล้วต้องกลับมาครบ 11 ข้อ
18. ทดสอบคีย์ลัด F5, Ctrl+E, Ctrl+S, Ctrl+1 ถึง Ctrl+4
19. แถบสถานะล่างต้องบอกจำนวนช่องที่ยังขาดได้ถูกต้องแบบเรียลไทม์
20. ทดสอบบนเครื่องที่ไม่มีฟอนต์ Leelawadee UI ต้องยังอ่านภาษาไทยได้ไม่เพี้ยน
21. ทดสอบที่ Windows Display Scaling 125 และ 150 เปอร์เซ็นต์
